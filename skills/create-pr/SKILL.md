# Create PR Skill

Generate a ready-to-paste PR title and body. The user submits it.

## Steps

### 1. Show Commits and Confirm

```bash
git log origin/main..HEAD --oneline
```

Present the list to the user and ask:
> "These are the commits that will be included in the PR — does this look right?"

Wait for confirmation before proceeding. If the user says no, ask which commits to include or what base branch to use instead.

### 2. Analyze the Changes

```bash
git diff origin/main...HEAD
```

### 3. Output PR Details

Print the following for the user to copy:

**Title** (≤70 chars, imperative mood, no trailing period):
```
<title here>
```

**Body:**
```markdown
## Summary
- <bullet 1>
- <bullet 2>

## Test plan
- [ ] <test step 1>
- [ ] <test step 2>

AIA HAb SeCeNc Hin R [model] v1.0

Vibe-Coder: [Human Name] <[human email]>
Assisted-By: [model] <claude@anthropic.com>

🤖 Generated by [model]
```

## AIA Attribution

**Short form:**
```
AIA HAb SeCeNc Hin R [model] v1.0
```

Where:
- `HAb` = Human-AI blend
- `Se` = Stylistic edits by AI
- `Ce` = Content edits by AI
- `Nc` = New content by AI
- `Hin` = Human-initiated
- `R` = Reviewed

**Model identifier — use whichever matches the current session:**
- Claude Code CLI: `Claude Code [Sonnet 4.6]` (substitute actual model)
- Claude Code Web: `Claude Code Web [Sonnet 4.6]` (substitute actual model)

**Statement URL (append when space allows):**
```
https://aiattribution.github.io/statements/AIA-HAb-SeCeNc-Hin-R-?model=[model]-v1.0
```

## Rules

- NEVER submit or create the PR — output only
- ALWAYS confirm the commit list with the user before drafting
- Title ≤70 chars, no trailing period
- Substitute the actual current model name — do not leave placeholder text
- Base branch is `main` unless the user specifies otherwise
