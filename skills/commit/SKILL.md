# Commit Skill

## Steps

1. Run `git status` and `git diff` to understand what changed
2. Draft a commit message following Conventional Commits format
3. Determine the correct attribution scenario (see below)

### NEVER EXECUTE Write or Update git commands
Never execute git commit, git add, git push - this skill is only to create or generate the actual commit message.  All git write/update operations will be executed by the user/human.

## Conventional Commits Format

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

**Types:** `feat` · `fix` · `docs` · `style` · `refactor` · `perf` · `test` · `chore` · `build` · `ci`

- Subject line: imperative mood, lowercase after the colon, no trailing period, ≤72 chars
- Body: explain WHY, not what. Wrap at 72 chars.
- Breaking changes: add `!` after type/scope (e.g. `feat!:`) or include a `BREAKING CHANGE:` footer

## AIA Attribution

**Short form to include in every commit body:**
```
AIA HAb SeCeNc Hin R [model] v1.0
```

Where:
- `HAb` = Human-AI blend
- `Se` = Stylistic edits by AI
- `Ce` = Content edits by AI
- `Nc` = New content by AI
- `Hin` = Human-initiated
- `R` = Reviewed

Evaluate what kinds of edits or new content was AI and offer the appropriate Se, Ce, or Nc components.

**Model identifier — use whichever matches the current session:**
- Claude Code CLI: `Claude Code [Sonnet 4.6]` (substitute actual model)
- Claude Code Web: `Claude Code Web [Sonnet 4.6]` (substitute actual model)

**Statement URL (append to body when space allows):**
```
https://aiattribution.github.io/statements/AIA-HAb-SeCeNc-Hin-R-?model=[model]-v1.0
```

## Attribution Trailers

**When AI (Claude Code) is doing the commit:**
The human is the creative director and co-author. Determine their name/email from `git config user.name` / `git config user.email`, the project's CLAUDE.md, or session context.

```
Vibe-Coder: [Human Name] <[human email]>
Co-authored-by: [Human Name] <[human email]>
```

**When a human is committing AI-assisted code:**
The human is the committer; the AI assisted.

```
Vibe-Coder: [Human Name] <[human email]>
Assisted-By: [model] <claude@anthropic.com>
```
